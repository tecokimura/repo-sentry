# v0.3 — scan→enrich→report→export 実用化リリース

リリース日: 2026-06-29

## 概要

scan → enrich → report → export（PDF）の4ステップパイプラインが実案件で動作することを確認し、 v0.3
として main にリリースします。

v0.3-stable（2026-06-22）は sentry-report Stable 宣言の内部マイルストーンでしたが、
本リリースではその後に実施した PDF 実用化・レポート構造改善・品質向上を含みます。

## v0.3 に含まれる内容

### Phase 1: sentry-scan（完了）

- Trivy・gitleaks によるスキャン
- CycloneDX SBOM 生成
- Clearwing 分析（Category / Impact / Affected Features）
- ecosystem / purl / fixedVersions / 修正コマンド生成
- KEV / EPSS 由来の優先度判定

### Phase 2: sentry-enrich（完了）

- OSV / CISA KEV / EPSS による外部 DB 補強
- SBOM を使った direct / transitive 判定
- 参考 URL 正規化（canonicalReference 生成）
- P3-2: PoC-in-GitHub 検知（OSV aliases / NVD reference から確認）

### Phase 3: sentry-report（Stable）

- urgency 3段階（immediate / planned / deferred）自動分類
- priorityScore による自動優先順位付け
- AI (gpt-4o-mini / Ollama) による理由文生成
- Renderer 側ガード（矛盾検出・フォールバック）
- `--plan-input` オプション（AI 再呼び出しなしで再生成）

### レポート構造改善

| 改善内容                 | 説明                                                     |
| ------------------------ | -------------------------------------------------------- |
| 推奨対応順序セクション   | 冒頭にサマリー表（今週中/今月中/次回定期）＋カードリスト |
| 後回し可能項目の圧縮     | per-CVE 詳細 → パッケージ単位集約テーブルに変更          |
| パッケージ別サマリー表   | 計画対応項目に複数 CVE を集約した表を追加                |
| 修正ガイドのコマンド分離 | 表からコマンド列を除去し `bash` コードブロックで表示     |
| deferred 決定論化        | `buildDeferReason()` で AI 非依存の理由文を生成          |

### P3-3: 品質確認（複数プロジェクト）

- CRITTER_PRIVATE_API-master・ReceiveAgent-server-develop・tecotec-lp-site-develop で動作確認
- max_tokens 不足による JSON 切り捨てを deferred 除外で根本解決
- Fix Guide の推奨バージョンをパッケージ最大値に統一

### P3-4: docker-run.sh 一括実行

- `scan → enrich → report` を1コマンドで実行
- SBOM 自動パススルー
- ログを `logs/<project>/` に分離
- ファイル名ハッシュ: プロジェクト名4文字 + sha256末尾4文字（計8文字）

### P3-5: sentry-export（PDF 生成）

- Chromium headless（puppeteer-core）+ Noto CJK フォントで PDF 生成
- セクション別色分け: 即時対応=赤、計画=橙、後回し=グレー
- 推奨対応順序カード（背景色＋左ボーダー）
- 推奨修正版を赤字太字で強調
- 付録テーブルのフォント縮小

## 主要コマンド

```bash
# 一括実行（scan → enrich → report）
bash scripts/docker-run.sh /path/to/project

# 個別実行
bash scripts/docker-scan.sh /path/to/project
bash scripts/docker-enrich.sh reports/.../scan_xxx.json
bash scripts/docker-report.sh reports/.../enriched_xxx.json

# PDF 出力
bash scripts/docker-export.sh reports/.../report_xxx.md
```
