## Phase 3 実装内容（v0.3 時点）

### コア機能

- `enriched.json` → `report.md` 変換
- AI (OpenAI / Ollama) による ReportPlan 生成
- urgency 3段階分類（immediate / planned / deferred）
- priorityScore による自動優先順位付け（KEV +40 / critical +40 等）

### 設計方針

- **分類は機械、文章は AI**: urgency・修正バージョン・コマンドは決定論的生成。AI は理由文のみ担当
- **Renderer 側ガード**: AI の出力が矛盾・不適切でも壊れないよう Renderer でガード

### Stable 達成に向けて修正した項目

| 項目                          | 内容                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| Ollama JSON 出力              | `response_format: { type: "json_object" }` を全プロバイダーに適用                   |
| deferReason 決定論化          | `buildDeferReason()` でパッケージ別に 5パターンの決定論的生成                       |
| CONTRADICTION_PATTERNS 修正   | assertive 表現のみにして過検出を排除（例: "即時対応" → "即時対応が必要"）           |
| P3-1: executiveSummary ガード | `sanitizeImmediateExpressions()` で immediate=0 時の矛盾文を文単位で除去            |
| Ollama 自動起動               | `docker-report.sh` で停止中の Ollama コンテナを自動 start                           |
| `.env` 読み込み修正           | `--env-file` + `-e KEY`（値なし）の pass-through 形式で OPENAI_API_KEY を正しく渡す |
| build スクリプト修正          | `${arr[@]+"${arr[@]}"}` パターンで `set -u` 時の空配列エラーを解消                  |

### `--plan-input` オプション

既存の `report-plan.json` を再利用して AI 呼び出しをスキップ。 Renderer の変更検証や費用削減に有効。

```bash
bash scripts/docker-report.sh enriched_xxx.json \
  --plan-input report_xxx-plan.json
```
